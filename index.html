🎮 人生はRPGとは？

人生には決められた攻略法はありません。このアプリは人生を代わりに決めず、自分の状態・願い・行動・経験・能力を整理し、次の選択肢を増やすための道具です。LevelやEXPは人間としての価値を表しません。

❤️ HP / 💙 MP

HPは今日、自分の身体をどれくらい使える状態か。MPは今日、頭や精神をどれくらい使える状態か。1〜5で自己評価し、20〜100に変換します。医学的な指標ではありません。

⚔️ Quest

Daily＝今日の具体的行動。Season＝一定期間で進める目標。Main＝現在の人生で重要な大きな目標。未達成は人生の失敗ではなく、期限超過も自動失敗にはしません。

✨ EXP / Level

MVPではQuest完了のみEXPを獲得します。Dailyは同じQuestの同じ日付で1回、Season/MainはQuest単位で1回だけです。Levelは累積EXPから自動算出され、手入力できません。

🧠 Skill

資格ではなく実際にできること。Lv.1＝知識がある、Lv.3＝簡単なことならできる、Lv.5＝一人で一通りできる、Lv.7＝かなり高い水準、Lv.10＝その分野の達人。Skill LvはEXPに影響しません。

💭 やりたいこと

願望・興味・可能性の保存場所。Quest化しても自動達成にはなりません。WantToDoからMain Questを作ることができます。

💾 Save / Backup

データ変更後に自動保存し、メニューから手動保存・JSON Export/Importができます。不正なImportは適用せず、現在データを保護します。
